How it works

  1. Extract: every day GitHub Actions downloads the new éCO2mix data (RTE, 15-minute points) and Open-Meteo temperatures for 8 cities into Parquet files.
  2. Transform and test: dbt on DuckDB types, deduplicates and aggregates them to hourly tables, then runs the data tests above. A failed test stops the run: no forecast is published on bad data.
  3. Forecast: a gradient-boosting model (scikit-learn) predicts the 24 hours of tomorrow from the calendar, holidays, temperature and consumption lags available at issue time.
  4. Score and publish: each forecast is logged, scored once measured, and this page is rebuilt.

Code, tests and design notes: github.com/Oradixx/france-grid-forecast
